2上电指示时序（Boot → App 主循环）

一次上电过程中，使用者看到的指示按时间顺序依次为：

① Boot 等待升级期（0 ~ 2.5s）
RUN 灯（PA2）100ms 快闪（5Hz，人眼可读；Boot_Led.c，指示“正在等待 IAP 升级命令”）；超时跳 App 前熄灭。若一直快闪不停 → 一直停在 Boot（无有效 App / CRC 失配）。
② App POST 彩灯自检
RGB 白常亮 200ms —— 三色硬件已全接，同亮即白，一次点亮即验证 R/G/B 三通道。
③ 上电回零（阻塞）
RGB 黄常亮（回零无法走 Tick 闪烁，用常亮示意）；失败自动重试至多 3 次，每次间隔 200ms 并清 DRV 故障。回零后保持黄衔接 POST。
④ 外设探测（POST，黄慢闪）
白闪自检后熄灭半拍进入黄慢闪：以模块探测窗口为节拍 —— 亮 ≈ 电机+UHF 窗口，灭 300ms 间隙，再亮 = AM 窗口（周期 ~1.4s，与业务回零黄慢闪同量级），阶段推进可辨。探测结果经调试串口 UART4 逐行打印，沉淀为 16bit 错误位图（见 §3）；上位机 RERUN 重探复用同一节拍。
⑤ 成功蜂鸣（1s）
电机 + UHF + AM 通信全部通过才响 1s；任一失败则静默，故障交由灯语表达。实机两轮复位验证 errBits=0 稳定。
⑥ 主循环稳态
RUN 灯进入 3s 呼吸心跳；ERR 灯按诊断态机动作；RGB 交仲裁器（§5）；蜂鸣脉冲由各触发源按需发出。

3自检体系（POST + 错误位图）

3.1 探测项与判据（App_BootSelfTest.c）

探测项方法（全部只读，不改变外设运行状态）失败位
电机 DRV8434SSPI 读回 CTRL3 微步档 + CTRL7 EN_SSC（与 init 写入值比对验证通信与落配置）+ FAULT 寄存器。rev_id 量产片默认 0，不参与判定。bit0 SPI / bit1 FAULT
UHF 模块App_UHF_Open（上电+配置）+ App_UHF_Query 只读探测链路；失败多为模块未装/无天线/上电慢于探测超时。bit2 UHF_COMM
AM 消磁器0x63 总查询（2A A2 63 01 01 02 00 00 67，必须 datalen=2）；解码器对半截帧会短暂失步，首查无应答时喂狗 + 延时 100ms 重试一次自愈。bit3 AM_COMM
行程开关回零失败 / 运行监控置位的 switchErr 并入（bit0=上触点 bit1=下触点）。bit5 TRAVEL_SW

3.2 错误位图（16bit 锁存）

位定义语义 / 清除方式
0x0001SELF_ERR_MOTOR_SPIDRV8434S SPI 配置回读不一致（通信/落配置失败）
0x0002SELF_ERR_MOTOR_FAULTDRV8434S 器件故障（FAULT 位）
0x0004SELF_ERR_UHF_COMMUHF Open/Query 通信失败
0x0008SELF_ERR_AM_COMMAM 消磁器 Query 通信失败
0x0010SELF_ERR_PARAM_CRC参数区 CRC 失败回落默认值，仅上电置位（引导期事实，不随探测刷新，只能手动 CLEAR）
0x0020SELF_ERR_TRAVEL_SW行程开关缺失 / 回零失败

位图可经上位机 FC_SELFTEST_CTRL (0x0F) 读 / 触发重探（RERUN 刷新外设位）/ 手动清除；另有 ReadLive 实时状态（motor 通信/故障寄存器、UHF/AM 链路、行程 switchErr）供在线诊断。

3.3 蜂鸣判据（本次扩定）

仅当 bits & (MOTOR_SPI | MOTOR_FAULT | TRAVEL_SW | UHF_COMM | AM_COMM) == 0 时蜂鸣 1s；任一失败静默。
即：电机自检（SPI 回读 + 器件故障 + 行程开关）+ UHF 通信 + AM(RS232) 通信 三者全过才响。参数区 CRC（bit4）不属于链路健康，不影响蜂鸣。上电默认不响（旧“上电即响”已移除），失败由灯语表达而非声音。
约束：所有探测阻塞调用之间必须喂狗（IWDG 2s 预算）。单次最长调用 = UHF Open（上电 100ms + 2 帧 ≈1.1s）< 2s；AM 首查最坏 1.2s + 重试前先喂狗。

4RUN 呼吸灯 与 ERR 诊断灯（App_Led.c）

4.1 RUN 呼吸心跳（持续，非状态语义）

周期
3s
300 步 × 10ms，前 1.5s 渐亮、后 1.5s 渐暗
曲线
伽马²
亮度 = 相位² × 999 / 150²，人眼对数感知 → 视觉均匀呼吸
实现
硬件 PWM
TIM2_CH3（PA2 默认映射）1kHz，亮度直写 CCR，零中断开销

主循环 AppLedProcess() 每迭代调用。作用 = “活着”心跳，与任何故障/业务状态无关，永不熄灭。

4.2 ERR 灯诊断状态机（仅触发期间动作，不锁存）

主循环 AppLed_KeyBlinkProcess() 每迭代调用，实时读取行程开关 / 光电输入。触发消失立即恢复正常（灭）。

触发条件ERR 灯表现设计意图
下行程 PC9 按住1000ms 慢闪（亮1000/灭1000）以周期区分按的是哪个触点；行程异常会关电机（安全），闪烁优先级最高，两键同按显示较慢的 1000ms
上行程 PC8 按住100ms 快闪（亮100/灭100）
仅 IR 光电 PC4 触发长亮与行程闪烁天然区分；IR 是检测事件非安全事件，用最温和的常亮
行程 + IR 同触发行程闪烁优先保持闪烁周期可辨是哪个行程；安全指示不被 IR 淹没
全无触发灭正常待机态

模式切换瞬间重置相位并从亮半周开始（避免“按下不亮”）；回 NONE 时立即熄灭。待机机构停在下触点，上电后 ERR 慢闪属正常现象。

5RGB 灯带灯语仲裁器（App_RgbLed_Pattern）

灯带无调光，图样 = 颜色掩码 + 闪烁周期/占空比。主循环每拍调用 App_RgbLedPat_Tick()，阻塞流程（OneShot 泵循环）内也必须调用，否则阻塞期间灯语冻结。单色同屏，每拍唯一图样，五级优先：

L1
行程开关错误（硬件安全，最高）
上行程错 = 黄闪 500ms · 下行程错 = 粉红闪 500ms · 两路同错 = 黄/粉红交替。直达 RgbLedHl_Set，压过一切。
L2
一次性闪显（事件确认，有限时长）
深度 1，新事件覆盖旧闪显，到期自动回落稳态。见 5.2 闪显表。
L3
稳态声明（各流程按槽位占位，最高优先级者胜）
槽位 = LOCKER / ONESHOT / MOTORTEST，每拍重复声明幂等，OFF 即撤销。见 5.1 图样表。
L4
上位机手动设色
任意 RGB 掩码，保持 10s（RGB_MANUAL_HOLD_MS）后自动回收；仅 IDLE 语义由 Dispatch 保证；mask=0 立即撤销。
L5
灭
无任何声明/手动 → 全灭（待机）。

值图样表现声明者 / 语义

5.2 一次性闪显（叠加在稳态之上，到期回落）

闪显表现语义（触发者均为业务层）
MATCH_OK绿单闪 200ms硬标签 EPC 匹配

触发源时长类别说明
