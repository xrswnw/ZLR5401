# Round_021 计划：RF 解码器接入（ZLR5401 参数双模）

> 2026-10-13 用户裁决落定，先梳理后实施。

## 一、业务语义定稿（裁决 1）

**RF 解码 = 与 AM 完全一致的基数计数模式：**

1. **一张标签只可解码一次**：标签被 RF 能量场去活化后不再报警（与 AM 消磁后静默同构，节奏待实测确认，不阻塞架构）。
2. **只根据数量解码，不识别标签**：固件无法也不试图识别"哪张/几张"标签——0x11 流程按上报帧计数（amCnt=N，收满 N 帧达标结账），与现行 AM 逐帧口径**完全一致**。
3. **已知误识别现象明示并接受**（与 AM 同款，客户已知）：
   - 单张标签的补杀/重试帧会被多计为多张（cmd17/0x3A 帧不带标签身份，无法区分）；
   - 多张同时放置时帧数与张数不保证一一对应；
   - 过路/邻域标签产生的帧会计入解锁数。
   上述均按 AM 现行口径处理，不做去重、不做身份判别。
4. 0x11 流程全套语义不变：受理开 → tmo 窗逐帧入账 → 达标/超窗/CANCEL → 出口关 + 模式看门狗保场。

## 二、固件形态定稿（裁决 2）

**ZLR5401 一版固件，参数切换 AM/RF 后端，二者互斥不兼容：**

1. **不是独立型号 ZLR5402**——一版固件覆盖两种外设（合同条款草案需相应改写）。
2. 参数区新增 `decoderType`（0=AM 缺省，1=RF），上位机命令可读写+持久化；**运行时单选**：同一时刻只初始化一个后端，不存在 AM+RF 并行/混接（接错外设 = 探链失败自检告警，不尝试自适应）。
3. 切换时机：**空闲时立即生效**（重建后端+重探链）；流程 busy 中收到切换命令回 BUSY；上电按参数区取值。
4. 旧参数区兼容：版本升级后读出 `decoderType=0`（AM），现网设备行为零变化。

## 三、架构方案

```
0x11/0x0A 流程层、Dispatch(AM_CTRL)、Bootloader 自检 —— 全部不动，继续走 App_AM API
        │
App_AM API（接口面不变：SetParam/GetParam/GetEventCount/GetLastEventMs/
           BurstActive/Process/Query/GetConfig/...）
        │
   后端分发层（新，按 decoderType 分派）
   ├── AM 后端 = 现 App_AM.c 整体平移（2A A2 帧 / cmd17 / 0x63 / 0x50 模式）
   └── RF 后端 = 新 RF 驱动（B5 A1 帧 / 0x3A 报警 / 0x01 查询 / 0x06 状态 / 0x04 心跳）
        │
共用 AM_HL（USART1 RS232 115200 + 环形缓冲 + 帧定位/分包）——帧头与校验常量参数化，由后端注入
```

关键点：
- **流程层零改动**是设计目标（0x11 的计数、看门狗、结账全部复用）；
- AM 后端 = 现有代码原样搬进后端槽位，回归风险最低；
- AM_CTRL 参数命令**透传原生命令字**，两模式各查各的命令表（AM: 0x11~0x67/0x50…；RF: 0x05~0x20/0x06…），固件不做翻译映射，文档双表并列——避免值域翻译（AM 命中 3-8 vs RF 6-15 之类）引入的语义损失；
- 诊断对齐：GET_STATUS 的 evt/deact 字段在 RF 模式下由 0x3A 计数/突发结算供给；0x01 返回的 4 字节累计报警数做对账校验源。

## 四、改动清单与工期（样机+节奏确认前提下 ≈ 2~2.5 周）

| # | 项 | 内容 | 估时 |
|---|---|---|---|
| 1 | 参数区 | decoderType + 版本升级 + 读写命令 | 0.5 天 |
| 2 | AM_HL 参数化 | 帧头/校验常量改后端注入 | 0.5 天 |
| 3 | RF 后端驱动 | 帧收发/0x3A 解析/0x01/0x06/0x04 心跳 | 2~3 天 |
| 4 | 后端分发层 | App_AM API 重定向 + busy 门禁 | 1 天 |
| 5 | AM_CTRL 双模式 + 自检 | 透传语义、AM_COMM 探链按模式选协议 | 1 天 |
| 6 | 真机闭环 | RF: 单张/多张/超窗/CANCEL/看门狗/心跳断链；AM: 全量回归（现网零回归红线） | 3~5 天 |
| 7 | 协议文档 | decoderType 命令 + RF 章节（含帧表双列） | 1~2 天 |

风险缓冲：0x3A 突发节奏与 AM 不构（看门狗静默参数重标定）+3~5 天；样机/标签到位时间不计入。

## 五、实施前置（不阻塞开发、但阻塞交付）

1. RF 样机 ×2 + 软/硬标签样品到位；
2. 一帧校验核对（电平接好后 10 分钟内可定：B5 A1 帧头 + Sum_L 算法）；
3. 0x3A 节奏实测（决定静默结算参数，架构上已隔离为后端常量）；
4. 灵敏度/阈值/能量双通道默认值取厂商推荐；
5. RF 设备自带 LED 配置为灭（避免与主控 RGB 灯语冲突）。
