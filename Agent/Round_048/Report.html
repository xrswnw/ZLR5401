1. 结论小结

本轮实现 UHF 操作优化 两项需求，均已编译通过（build_app.sh，0 error / 0 warning）：

  • 盘点实时返回 EPC：新增标签实时推送回调 + UHF_SUB_PUSH_EPC 主动上报帧，盘点到一帧 EPC 即经 USB 推给主机，不再需要主机反复 GET_TAGS 分步拉取。
  • 自动扫描（测距）：新增 UHF_SUB_SET_SCAN 持续自动盘点，读到场内 EPC 即推送 + 蜂鸣器 100ms 短鸣，用于测试读距；并实现空闲超时自动停扫与防过度节流。

3. 协议变更

cmd方向data说明
0x0D SET_SCANH→D [cmd, timeoutL, timeoutH, beepEn, minIntL, minIntH] 启动自动扫描(测距)；timeout(ms, 下限 200)=无标签空闲窗口自动停扫；beepEn=1 读到蜂鸣 100ms；minInt=节流间隔(0 取消)
0x0E SCAN_STOPH→D[cmd]停止自动扫描并停止当前盘点
0x0F PUSH_EPCD→H[cmd, epcLen, epc..]设备主动推送一帧盘点到的 EPC（FC=0x0B）
实时推送与请求-响应并存

原 INVENTORY(0x03) / GET_TAGS(0x0A) 保留不变，向后兼容。实时推送是叠加能力：任何盘点/扫描（含开锁器复用）每次读到 EPC 都会推一帧，主机可即时呈现。

4. 蜂鸣设计（短鸣 vs IR 闪烁不冲突）

蜂鸣器同一 GPIO 被 光电 IR 遮挡周期闪烁 复用。本轮新增一次性脉冲调度：

  • App_NewPeriph_BeepPulse(100)：立即响，记录截止时刻，App_IrBuzzer_Process 在脉冲未到期阶段让出控制权，保证 100ms 短鸣完整呈现；到期自动静音。
  • 防过度：扫描内相邻标签动作间隔 < minInt 时跳过蜂鸣（同标签高频重复不刺耳、不上报洪泛），但仍推送实时 EPC 事件。

// App_UHF.c — 标签推送 + 扫描节流
static void uhf_tag_push(const AppUHFTag_t *t) {
    ... 入缓冲, s_scanLastTagMs = now ...
    if (s_scanActive && s_scanBeep) {                 // 防过度: 节流蜂鸣

    }

// App_UHF.c — 自动扫描驱动 + 空闲超时停扫
if (s_scanActive) {
    if (s_scanIdleBaseMs==0) s_scanIdleBaseMs = now;
    if (s_scanLastTagMs > s_scanIdleBaseMs) s_scanIdleBaseMs = s_scanLastTagMs;
    if (s_scanTimeoutMs && (now - s_scanIdleBaseMs) >= s_scanTimeoutMs) {
        s_scanActive = 0; App_UHF_Stop();             // 超时自动停扫
    } else if (!App_UHF_IsBusy()) {
        App_UHF_Inventory();                          // 维持持续盘点
    }
}

7. 建议（后续可考虑）

  • 上位机侧：订阅 PUSH_EPC 帧即时刷新盘点列表；结合 RSSI（当前模块 0x21 无元数据，RSSI 暂恒 0）如需测距分级需改走带元数据盘点。
