ZLR5401 单条同步开锁指令设计方案 v2 — 行程开关锚定 + UHF 持续监控

轮次：Round_074 ｜ 生成：2026-08-29 ｜ 性质：设计方案 — 待确认后实施
v1 → v2 变更（用户 2026-08-29 指示）：①升起目标由固定 4800 步改为 升到 KEY_UP 上行程开关；②保持阶段改为 UHF 持续盘点在线监控；③回降目标 = 回退到 KEY_DOWN 下行程开关；④回降触发 = 流程结束(标签稳定移除) / 超时 / UHF 中途变更；⑤须处理盘点超时、防抖稳定判据、失败安全回退。
备份：Round_074_20260829_200202（设计阶段不改固件代码）

1. 需求解读（v2）

  • 一条指令：一帧带全 —— UHF 盘点超时 + 最大保持窗口 + 期望 TAG（EPC）+ RFU。设备自行解析执行。
  • 单标签判断：UHF 同步盘点一轮，读到的标签与帧内 TAG 比对，命中才继续。
  • 符合 → 升起：电机上行直到触发 KEY_UP 上行程开关（绝对位置锚定，不再固定步数），停住保持。
  • 保持期间在线监控：UHF 持续盘点（一轮接一轮不停），实时监视期望标签在场状态。
  • 回降触发（三选一先到先回）：
    1. 流程结束 = 期望标签稳定移除（防抖确认，非单次漏读）；
    2. 超时 = 保持窗口到最大时长；
    3. UHF 变更 = 读到内容变化（期望标签消失后读到其他 EPC）或 UHF 链路中断（无法继续证实标签在场，安全优先视为变更）。
  • 回降：下行回到 KEY_DOWN 下行程开关（绝对位置基准，建立下次开锁的确定起点）。
  • 同步阻塞：全流程（含保持阶段）完成或失败那一刻回一帧，带详细失败码与结束原因。

2. 请求帧格式（不变部分沿用 v1）

53 77 addr 00 len(2,LE) 0D 08 tmoL tmoH maxHoldL maxHoldH epcLen EPC[0..11] rfu1 rfu2 CRC32(4)
字段偏移长度取值说明
cmd010x08LOCKER_SUB_ONE_SHOT
tmoMs120~10000初始判定盘点的超时。0 = 默认 1000 （保持阶段的盘点周期固定 1000ms，不受此参数影响）
maxHoldMs320~60000保持阶段最大时长（超时触发回降）。0 = 默认 30000。上限 60s（阻塞上限约束，见 §6）
epcLen511~12期望 EPC 长度
epc6epcLen—期望匹配的硬标签 EPC
rfu6+epcLen0~N0x00保留（现全 0）

帧 ~31B、响应 ~30B，均单 HID report 承载，无拆帧。

3. 响应帧与失败码总表（v2 新增 endReason / retreat 状态）

3.1 响应骨架

data[0]=cmd(0x08) data[1]=err data[2]=endReason(仅 err=0 时有效) data[3..]=诊断字段(随 err)

3.2 成功时的 endReason（为什么回降）

值宏含义
1ONE_END_TAG_REMOVED期望标签稳定移除（防抖确认，正常业务完成：客户取走商品）
2ONE_END_HOLD_TIMEOUT保持窗口超时（maxHoldMs 到期）
3ONE_END_TAG_CHANGEDUHF 变更：期望标签稳定消失后读到其他 EPC
4ONE_END_UHF_LOST保持期间 UHF 链路中断（无法证实标签在场，安全优先回降）

3.3 失败码总表

err宏名含义触发条件诊断字段
0x00ONE_ERR_OK全流程完成（升到位→监控→回降到位）— endReason(1), epcLen, epc(命中EPC), riseSteps(2), lowerSteps(2) — 升/降 = KEY_UP/KEY_DOWN 触点间的实际步数，可作行程健康度参考
0x01ONE_ERR_BUSY资源忙Locker 非 IDLE / UHF 自动扫 / 电机运动中 lockerState, uhfState, stepperState
0x02ONE_ERR_PARAM参数非法epcLen=0/>12 / 帧长不符无
0x03ONE_ERR_UHF_OPENUHF 上电/配置失败App_UHF_Open() ≠ OKuhfRawErr
0x04ONE_ERR_UHF_LINKUHF 通信失败（初始盘点）InventorySync() 链路负值uhfRawErr
0x05ONE_ERR_NO_TAG初始盘点一张都没读到InventorySync = 0 张uhfRawErr
0x06ONE_ERR_MISMATCH读到标签但 ≠ 期望初始盘点无命中 tagsFound, epcLen, epc(读到的第一张)
0x07ONE_ERR_HOMING未回零/行程开关错误Homing 未就绪switchErr
0x08ONE_ERR_MOTOR_FAULT升降中电机故障（含触点不可达）FAULT/DIAG2/nFAULT；或升到步数上限仍未触 KEY_UP / 降同理 fault, diag1, diag2+pin(2), steps(3), phase(1:升/2:降), retreat(1:0=回退成功 1=回退失败 2=未尝试)
0x09ONE_ERR_MOTOR_TIMEOUT升降超时单段 >10s / 步数停滞steps(3), phase(1), retreat(1)
安全回退原则（v2 核心）：升段/保持段任何失败，若磁块不在 KEY_DOWN，必先尝试回退到 KEY_DOWN 再回帧；回退结果记入 retreat 字段（回退失败不掩盖原始错误码，但让上位机知道设备停在半程）。初始盘点/比对阶段的失败（0x03~0x06）磁块未动，retreat=2 不尝试。

4. 固件内部阻塞流程（v2 全景）

FC_LOCKER_CTRL case 0x08 — 全程阻塞, 每个泵循环: {App_UHF_Process(); App_Stepper_Process(); IwdgHl_Feed(); DelayMs(20);}

 ⑴ 前置检查 (不阻塞)
     epcLen 合法? Locker==IDLE? UHF 非扫? 电机 IDLE? Homing 就绪?
       → PARAM / BUSY(带三态) / HOMING(带 switchErr)

 ⑵ UHF 就绪 (阻塞 ~100ms+配置)
     App_UHF_Open()  失败 → UHF_OPEN

 ⑶ 初始同步盘点 + 单标签判断 (阻塞 ≤ tmoMs+500)
     App_UHF_InventorySync(tmoMs)
       链路负值 → UHF_LINK / 0张 → NO_TAG / 全不命中 → MISMATCH(带读到的EPC)
     命中 → 记录期望 EPC, UHF 保持供电, 转异步持续盘点

 ⑷ 升起: 驱动上行至 KEY_UP 触点 (阻塞, 目标=开关不是步数)
     App_Stepper_Move(dir=0, 持续) + 泵循环:
       App_NewPeriph_ReadKeyUp()==0 → 触到 → DcBrakeStop + ClearFault, 停在 KEY_UP
       瞬态误停(<50步+fault≠0) → 清障重试 1 次          回零既有判据 App_MotorHoming.c:100
       步数停滞>400ms / 超 HOMING_UP_MAX / 超10s         seek_switch 既有兜底 App_MotorHoming.c:42
         → MOTOR_FAULT/TIMEOUT (phase=1)
       // 此段泵循环同时推进 UHF_Process: 盘点不中断, 升起期间标签若被取走也会被⑸看到

 ⑸ 保持: UHF 持续盘点在线监控 (阻塞, 最长 maxHoldMs)
     泵循环: UHF 空闲→App_UHF_Inventory() 再起一轮(1000ms); TagTake 逐张取
     在场判定 (防抖, 连续漏读≠移除):
       lastSeenMs  = 期望 EPC 最近一次被读到的时间戳
       每读到期望 EPC → lastSeenMs = now, 清其他状态
       REMOVED_CONFIRM_MS(默认3000) 内再未读到 → 稳定移除确认
       若移除确认时读到过其他 EPC → endReason=3 TAG_CHANGED, 否则 =1 TAG_REMOVED
       UHF 链路断(ERROR 态/Inventory 反复无响应 ≥ UHF_LOST_CONFIRM_MS) → endReason=4 UHF_LOST
       now ≥ holdStart+maxHoldMs → endReason=2 HOLD_TIMEOUT
       // 单次盘点空手 = 正常RFID漏读, 不触发任何回降, 只刷新"未读到"计时
       // 非期望 EPC 在场但期望 EPC 仍在 → 忽略 (旁边客户, 不影响本场)
       // 防抖窗口内 UHF 盘点自身超时: 连续3轮空回但总时长<确认窗 → 仍视为在场, 继续等

 ⑹ 回降: 下行至 KEY_DOWN 触点 (阻塞, 同⑷ 镜像)
     App_Stepper_Move(dir=1, 持续) + 泵循环:
       ReadKeyDown()==0 → DcBrakeStop + ClearFault → 到位 (绝对基准恢复)
       同款异常处理 → MOTOR_FAULT/TIMEOUT (phase=2, 带 retreat 字段=回退失败)
     // 回降期间 UHF 停扫 (UHF_Stop), 磁块已下, 不再需要监控

 ⑺ 返回
     err=00: [08, 00, endReason, epcLen, epc, riseSteps, lowerSteps]
     失败:  按 §3.3 (含 retreat 状态)
     // 典型耗时: 盘点1s + 升~1.5s + 保持(事件驱动, 3s~60s) + 降~1.5s

5. UHF 持续监控的防抖状态机（⑸ 详解，v2 新增）

              每轮盘点(1000ms)结果                     连续确认窗
 ┌─────────┐  读到期望EPC   ┌──────────────┐  REMOVED_CONFIRM_MS 内无期望EPC
 │ PRESENT │ ◄──────────── │   (持续在此)   │ ─────────────────────────────┐
 └─────────┘               └──────────────┘                              │
      │ 未读到(单次漏读)▼                                                 ▼
 ┌─────────┐   再次读到期望EPC → 回 PRESENT          ┌────────────────────┐
 │ MAYBE_  │ ─────────────────────────────          │ REMOVED-CONFIRMED  │→ endReason:
 │ GONE    │  (漏读自动恢复, 不回降)                 │ 期间读到其他EPC?    │  3=CHANGED / 1=REMOVED
 └─────────┘                                      └────────────────────┘
 并行计时器:
   holdTimer: holdStart → maxHoldMs 到期           → endReason=2 (最高优先级先到先判)
   uhfLinkTimer: Inventory 发出后 UHF_LOST_CONFIRM_MS 无任何响应帧 → endReason=4
防抖参数默认值依据
REMOVED_CONFIRM_MS 稳定移除确认窗3000 ms≈3 个盘点周期。RFID 单轮漏读常见，3 轮连续不见才确认，兼顾响应速度与误判
INVENTORY_PERIOD_MS 保持阶段盘点周期1000 ms= App_UHF_Inventory() 既有默认
UHF_LOST_CONFIRM_MS 链路失联确认5000 ms连续 5s 收不到任何 UHF 响应帧 → 判链路坏。模块重启/瞬态恢复期间不至于立刻误回降
HOLD_MAX_MS 阻塞硬上限60000 ms主循环冻结的容忍上限（§6），maxHoldMs 参数被钳到此值

三个参数以宏定义形式放 App_LockerOneShot.h，后续可按现场实测漏读率调整，不动协议。

6. 边界与既定决策（v1 待确认项已按 v2 需求落定）

#事项v2 决策
①阻塞期间主循环冻结（LED/蜂鸣IR/Locker 状态机停，无法响应任何新命令） 接受。总时长被 maxHoldMs(≤60s) + 升降(各≤10s) + 盘点(≤10.5s) 三段钳位，最坏 ~90s 全程喂狗不复位。期间 IWDG/TIM4/SysTick/USART/USB 中断照常。上位机在阻塞期间不得发送其他命令（同步语义，HID OUT 会积压）
②升/降目标升到 KEY_UP 触点、降回 KEY_DOWN 触点（绝对位置锚定），寻触驱动套用回零 seek 既有兜底（停滞/超步/超时）
③升降速度/转矩沿用回零参数 2000Hz / 40%——寻触驱动工况与回零完全相同，直接复用已验证数值
④maxHoldMs=0 语义=默认 30000ms
⑤失败安全回退升段/保持段失败必先回退 KEY_DOWN，retreat 字段上报回退结果；初始判定阶段失败磁块未动不回退
⑥保持期间非期望 EPC 同场忽略（只要期望 EPC 仍在场）——仅当期望 EPC 稳定消失后才看是否出现其他 EPC 决定 CHANGED/REMOVED 区分
⑦升到位后保持期间电机断输出（DcBrakeStop 后无保持电流）——磁块由机械/磁自锁，与现有 Locker 路径一致；若现场要求通电保持转矩，属参数调整再议
⑧本指令与 App_Locker 状态机完全旁路，不碰 Locker 上下文；互斥靠 ⑴ 前置检查（Locker 须 IDLE）
