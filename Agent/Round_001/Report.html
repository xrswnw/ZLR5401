5. Bootloader 冗余清理（Round_003，激进）

目标：清理 Boot 中与官方 USB HID 升级无关的冗余，同时确保升级功能零改动。

  - Boot_Uart.c / Boot_Uart.h      -> TrashCan/Round003_Boot_UART_DBG/

  - main.c: Uart_Init()/USART2+DMA 复位清理移除
  - Boot_Config.h: HOST_UART / DBG_UART 配置块移除, RCC 归并
  - System_PeriphClk.c / Boot_Led_HL.c: 相关注释清理
  - stm32f10x_it.c: 重写, 移除 ST 模板冗余, 保留 8 个升级处理器 IRQ
升级功能保留验证： 
协议处理器 (全部 8 个, 零改动):
