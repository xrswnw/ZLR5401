4. CRC 算法与示例帧（尾部新增章节方案）

  • 算法规格：CRC32/MPEG-2 —— poly=0x04C11DB7、init=0xFFFFFFFF、无输入/输出反射、无最终 XOR；覆盖帧头至 data 全部 N+7 字节；结果 4B 小端尾附。附 C 与 Python 参考实现各一份（各 ≤15 行）。
  • 示例帧（Host→Device 请求帧全字节 + 逐字段标注）：
    1. 握手：FC_HANDSHAKE (0x01, 空参数)——9 字节完整帧。
    2. 盘点：UHF OPEN (0x21/0x01) + INVENTORY (0x21/0x03, tmo=1000ms) 两帧。
    3. 解锁 1 标签：LOCKER UNLOCK_MULTI (0x23/0x0A)，epcCnt=1, epcLen=6 示例 EPC。
    4. 解锁 2 标签：epcCnt=2（含窗 W 计算：120s+(2−1)×30s=150s）。
    5. 解锁 3 标签：epcCnt=3（W=180s；帧长 8+3×6=26B data，单 HID 帧装下）。
    每帧给出：53 77 01 00 len_lo len_hi func data… crc(4B LE) 完整十六进制 + 字段表格。响应帧示例取实机捕获（见 §5 验证），不手造。
  • 可扩展性：示例帧按"场景 → 帧"小节化，后续新增场景（写标签/软标解锁等）直接追加小节，不动结构。
  • CRC 数值生成方式：实现期用 Python 现算（与固件 Crc32Calc 同参数），并实机回验——把文档示例字节原样发给设备，设备能正常回帧即证明 CRC/字节序正确；再发一个故意改坏 CRC 的变体确认设备静默丢弃。
