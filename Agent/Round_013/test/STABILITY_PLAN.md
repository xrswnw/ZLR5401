# ZLR5401 Round_013 稳定性测试方案

固件: **App_202609191401** (速率统一 1000µsteps/s + 微步 400/圈 + TIM4 两档 PSC + 瞬态判线 200)
日期: 2026-09-19 · 状态: **待裁决执行** (Round_011 先例: 方案定稿→裁决→执行)

## 目标

1. **电机稳定性**: 上电回零、首驱瞬态、1000 节拍、机械重复定位、连续运行故障/温升
2. **0x10 流程稳定性**: 长循环 soak、多标签对抗、打断矩阵、边界参数、状态机无泄漏
3. **系统级**: 无自复位 (IWDG)、协议一致性、计数器回绕

## A. 电机稳定性

### A1 上电回零压测 — 20 次软复位 + 5 次冷断电
- 每次: 必须回零 **READY**; 黑匣子首驱瞬态死点 <200 步 (走立即同腿重试, 无 200ms 停顿);
  双腿 reason=1 正常触点停机; switchErr=0x00
- 聚合统计 (A5): 瞬态触发率、死点步数分布 (当前样本 ~100±15, 对 200 判线裕量)、
  fault 码一致性 (0xC0)、boot→READY 时长分布 (~17s: 8.5s 静置 + 2×4.2s 腿)
- 腿步数分布 (4172~4253 现带宽) **±1.5% 且无趋势漂移** (漂移=机构松脱/磨损信号)
- 工具: 新写 `boot_stress.py` (循环 FC_RESET→等枚举→盯 READY→导出 trace→jsonl 台账);
  冷断电由人工配合断电再上电

### A2 连续运行 soak — 与 B1 合并, 15 分钟
- 0x10 循环窗 timeoutSec=900, 标签静态在门上 → ~70 周期 / ~140 电机腿, 70% 运动占空
- 判据: 0 失步 / 0 nFAULT / 0 器件故障; 设备不得自复位 (HID 断连检测);
  TRQ 观察 (是否出现热降转矩迹象); 噪音/振动主观对比 (起始 vs 末尾, 1000 恒速)

### A3 机械重复定位 (A2 数据判读)
- 全周期 rise/lower 步数分布: 单峰紧带=好; **双峰**=开关抖动/两位置触发;
  **趋势漂移**=机构松脱; 采样 flags 中 KEY 位中途置位=开关信号毛刺 (回零误判风险)

### A4 速率矩阵 — TIM4 两档 PSC 边界验证
- `MOTOR_CMD_SPEED`+`MOTOR_CMD_MOVE` 组合, 从 READY 底位: 升 N@R → 降 N@R (往返抵消),
  R ∈ {2000, 1500, 1200, 1000, 800, 400, 100, 50, **15**, **1**} (N 按档选, 每动 ≤8s;
  ≤15Hz 专验 10kHz PSC 慢档), 测毕 FC_RESET 回零
- 判据: 黑匣子每腿 steps/runMs ≈ 请求速率 (含停机 10ms 节拍+DC 制动 8ms 开销, ±1%)

### A6 故障路径 — 观察项, 不主动堵转
- 主动堵转=机构研磨风险, **默认不做**; A1/A2 若出现任何腿失败, 黑匣子已自动含路径
  (reason/fault/TRQ 轨迹), 按 motor_trace.py 判读法归因。主动堵转测试需用户显式裁决

## B. 0x10 解锁流程稳定性

### B1 长循环 soak (=A2)
- 窗末 ALL_OK / TIMEOUT(≥1 ok); 偶发周期失败允许 (读率抖动) 但必须走正规路径:
  回退+黄慢闪+lastCyc=2/3 上报, 自愈进下一周期
- 不允许: 卡死 / 电机停半程 / 终帧缺失 / UHF 状态残留 (IO_DIAG uhfPowered/状态复核)

### B2 标签矩阵 (含多标签对抗)
| # | 场景 | 方法 | 判据 |
|---|---|---|---|
| a | 单标良好位 | 判据耗时 ~0.5s, 单轮 | ALL_OK 基线 |
| b | 单标临界位 | 判据 4~5s (本轮实测位置), 循环 120s | 周期失败全走正规路径自愈 |
| c | **双标签对抗** | 期望标+干扰标同时在读区: ①全程; ②中途拿走干扰标 | ①**永不确认, 电机 0 动作**, 窗满 TIMEOUT; IO_DIAG vMiss/最后EPC/tagsFound 反映外来在场; ②拿走后数秒内确认开盘 |
| d | **外来替换** | 升起后取走期望标+放外来标 (挡红外) | 10 miss→周期失败 **lastCyc=3(更换)**→回退; 外来**不得触发再升** |
| e | **远距乱跑对抗** (回归今晨修复) | 电机已复位, 标签放远处可间歇读、不挡红外, 持续 ≥2min | 电机**不得升起** (0 次); 放回门上(挡红外)→正常下一轮 |
| f | 回退中放回 (re-rise) | 回退半程把**期望**标放回门上 | 中停回退→免闸直接再升; 放回外来无效 |

### B3 打断矩阵
- CANCEL @ {WAIT_TAG, 确认中, 升起中, 保持中, 回退中(带/不带回归)} × 5 次
- 判据: 立即回 OK + 安全回降到底 + 终帧 ABORTED; 事后 IO_DIAG lockerState=IDLE、
  homing=READY、UHF 态干净; 紧接新流程行为与首跑一致 (无状态残留)

### B4 并发轮询
- 流程中 GET_PROGRESS 100ms 连拍 (epc_progress_poll.py): phase/cycleOk/lastCyc/elapsed
  单调合理; 对比无轮询基准, 判据耗时漂移 ≤10% (轮询不干扰流程节拍)

### B5 边界参数
- timeoutSec ∈ {0 单轮, 1, 255}; holdTop ∈ {最小, 最大}; tmo ∈ {30, 100, 255};
  EPC 长度边界 {最短, 12, 最长, 全FF}; 非法帧 (超长/零长 EPC) → 拒绝路径
- 判据: 全部合法终帧, 无卡死, 无 BUSY 泄漏

### B6 蜂鸣/灯语人检清单 (soak 期间人工核对, 无遥测通道)
- 确认=绿单闪**无鸣**; 回退**开始**=800ms 鸣 (非到底才鸣); 流程结束=1s 鸣;
  周期失败=黄慢闪; 链路断=红双闪

## 通过标准 (总)

1. 回零 25/25 READY、0 FAILED; 瞬态全被立即重试吸收 (死点 <200)
2. soak: 0 电机故障 / 0 自复位 / 0 卡死; 步数分布带宽内; 周期失败全正规自愈
3. **多标签/替换/远距对抗: 电机误动 0 次** (乱跑+多标签语义保持)
4. 打断 100% 全复位无泄漏; 边界参数 100% 合法终帧
5. 速率矩阵各档 steps/时长比 = 请求值 ±1%
